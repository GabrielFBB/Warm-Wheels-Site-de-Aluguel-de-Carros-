Warm Wheels | Python, Flask, CSS
O Warm Wheels é uma plataforma web de aluguel de veículos desenvolvida em Python e Flask, criada para facilitar o
processo de reserva de carros e motos de forma simples e organizada. O sistema permite cadastro e login de usuários,
pesquisa de veículos, filtros por categoria e preço, além da realização e gestão de reservas online.
O principal problema que o projeto resolve é a dificuldade e falta de organização em sistemas tradicionais de aluguel de
veículos, automatizando o controle de disponibilidade, reservas e informações dos veículos, tornando o processo mais
rápido, eficiente e intuitivo tanto para clientes quanto para a gestão da empresa.
